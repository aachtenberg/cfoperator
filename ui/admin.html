MCP connectors

MCP servers whose tools the console chat may use. Each tool joins the chat as mcp_<name>_<tool>. Chat only: investigations, sweeps and triage never see them. A tool the server does not mark read-only is treated as a write, so members are not offered it and an admin's call is logged with its arguments. Streamable HTTP servers only; header values are stored encrypted and never shown again.
